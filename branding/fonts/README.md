# Manrope

The original variable font is bundled from the [Google Fonts Manrope directory](https://github.com/google/fonts/tree/main/ofl/manrope), retrieved on 2026-11-05.

- `Manrope-Variable.ttf`: original upstream font, weight axis 200-800.
- `Manrope-Regular.ttf`: static instance at weight 400.
- `Manrope-Semibold.ttf`: static instance at weight 650, used for the brand's display setting.
- `Manrope-Bold.ttf`: static instance at weight 750, used for wordmarks and emphasis.

The static instances are produced from the bundled variable font by `tools/build.py`. They keep the original copyright and font license. The complete SIL Open Font License is in [OFL-Manrope.txt](OFL-Manrope.txt).

Logo and banner SVGs contain outlined text, so consumers do not need these fonts installed. The fonts remain available for new layouts and editable typography.
